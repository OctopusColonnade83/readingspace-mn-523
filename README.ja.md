## 読書の次のアクションを、読んでいる内容のそばに

PDF、Web ページ、ノートを読んでいるとき、次に必要になるのは、概念の説明、追加の質問、抜粋の読み上げ、Web での事実確認などです。Reading Space MN はこれらを一つの読書ワークフローにまとめ、リーダー、ブラウザ、AI ツール、ノートアプリの間を行き来する負担を減らします。

MarginNote を置き換えるものではありません。目の前の内容を調べ、理解し、聴き、残すための入口を追加します。

## 利用シーン

- 選択した文章をすばやく説明、辞書検索、翻訳し、続けて質問する。
- 抜粋やマインドマップカードを読み上げ、コメントし、関連カードを作成する。
- 読書フローを離れずに内蔵ブラウザで資料を検索・確認する。
- 価値のある抜粋やカードをローカルの Obsidian ReadingSpace に送る。
- 明示した範囲の設定をエクスポート、インポート、または手動同期する。

## 主な機能

| 機能 | 内容 |
| --- | --- |
| **選択範囲・カードツールバー** | 選択範囲、抜粋、マインドマップカードのそばから、読み上げ、説明、AI 質問、コメント、子カード・兄弟カード作成を実行できます。 |
| **AI クイック説明・検索** | 選択範囲やカードを簡潔に説明し、辞書、翻訳、追加質問へ進めます。 |
| **AI 質問** | 自分で設定したプロバイダー、モデル、Endpoint、プロンプトを使う独立パネルを開きます。 |
| **内蔵ブラウザ** | 読書中の Web 調査に加え、ホームページ、ブックマーク、閲覧履歴、現在のタブを管理します。 |
| **音声読み上げ** | 設定済みの TTS サービスまたはローカル Obsidian ブリッジで音声を生成し、独立プレーヤーで再生します。 |
| **Obsidian 送信** | 現在の抜粋やカードをローカル Obsidian ReadingSpace の指定フォルダーへ送ります。 |
| **設定・手動同期** | 外観、AI、ブラウザ、音声、エクスポート設定を管理し、選択した iCloud データを手動でアップロード・インポートします。 |

## 基本的な流れ

1. MarginNote で文章を選択するか、抜粋またはマインドマップカードをタップします。
2. Reading Space ツールバーから、読み上げ、説明、検索、AI 質問、カード操作を選びます。
3. 独立パネルまたはプレーヤーで結果を確認し、必要なら質問を続けます。
4. 残したい内容をローカル Obsidian へ送り、または設定画面から選択したデータを手動で処理します。

## 現在の状態

現在の公開ソーススナップショットはバージョン **0.1.5** で、実行には **MarginNote 4.2.3 以降**が必要です。

> [!IMPORTANT]
> 正式な `0.1.5` `.mnaddon` パッケージは [GitHub Release の Reading Space MN v0.1.5](https://github.com/Awaker-OTE/readingspace-mn/releases/tag/v0.1.5) からダウンロードできます。ソースから生成した成果物は引き続きローカル開発・検証用であり、Release に添付された検収済みパッケージの代わりにはなりません。

利用上の重要な制約：

- AI と TTS には、自分で用意したプロバイダー、Endpoint、API Key、または接続情報が必要です。第三者の認証情報は同梱されていません。
- 自動同期は実験機能で、現在停止中です。設定の保存時に自動アップロードは行われず、iCloud への手動アップロードとインポートのみ利用できます。
- ブラウザの Cookie とログイン状態はローカルに保持され、設定のエクスポートや iCloud 同期には含まれません。
- ローカル Obsidian ブリッジは主にデスクトップ向けで、iPad では利用できません。
- MarginNote のバージョン、端末、ネットワーク環境によって動作が異なる場合があります。

## ソースの検証とビルド

プラグインの実行には MarginNote 4.2.3 以降が必要です。公開ソースのビルドには、Node.js 22.12 以降、pnpm 10 以降、システムの `zip` コマンドも必要です。

```bash
git clone https://github.com/Awaker-OTE/readingspace-mn.git
cd readingspace-mn
pnpm install --frozen-lockfile
pnpm verify
pnpm build
```

`pnpm verify` は公開範囲、ソーススナップショット、機能契約を検証します。`pnpm build` は固定名とタイムスタンプ付きの `.mnaddon` を `artifacts/` に生成しますが、プラグインのインストール、MarginNote の再起動、デスクトップへの書き込み、内部公開サービスの呼び出しは行いません。

公開ビルドは再現性と回帰確認のためのもので、検収済みの正式配布物を置き換えるものではありません。
