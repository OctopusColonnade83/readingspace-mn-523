## Следующее действие — рядом с читаемым материалом

При чтении PDF, веб-страницы или заметки часто нужно объяснить понятие, задать дополнительный вопрос, прослушать выдержку или проверить источник. Reading Space MN объединяет эти действия в одном процессе и уменьшает переключения между ридером, браузером, инструментами ИИ и приложением для заметок.

Плагин не заменяет MarginNote. Он добавляет точечные способы исследовать, понимать, слушать и сохранять уже открытый материал.

## Сценарии использования

- Объяснять, искать, переводить выделенный текст и задавать дополнительные вопросы.
- Озвучивать и комментировать выдержки и карточки интеллект-карт, создавать связанные карточки.
- Искать и проверять материалы во встроенном браузере, не покидая процесс чтения.
- Отправлять ценные выдержки и карточки в локальное хранилище Obsidian ReadingSpace.
- Экспортировать, импортировать и вручную синхронизировать выбранные настройки в явно заданных границах.

## Основные возможности

| Возможность | Назначение |
| --- | --- |
| **Панель выделений и карточек** | Добавляет озвучивание, объяснение, вопросы ИИ, комментарии, дочерние и соседние карточки рядом с текущим материалом. |
| **Быстрое объяснение и поиск с ИИ** | Даёт краткое объяснение и доступ к словарю, переводу и дополнительным вопросам. |
| **Вопросы и ответы с ИИ** | Открывает отдельную панель с вашим провайдером, моделью, Endpoint и подсказками. |
| **Встроенный браузер** | Поддерживает веб-поиск внутри чтения и управляет домашней страницей, закладками, историей и текущей вкладкой. |
| **Озвучивание** | Генерирует звук через настроенный TTS-сервис или локальный мост Obsidian и передаёт его отдельному проигрывателю. |
| **Отправка в Obsidian** | Передаёт текущую выдержку или карточку в выбранную папку локального Obsidian ReadingSpace. |
| **Настройки и ручная синхронизация** | Управляет внешним видом, ИИ, браузером, звуком и экспортом, а также ручной загрузкой и импортом выбранных данных iCloud. |

## Типичный процесс

1. Выделите текст, выдержку или карточку интеллект-карты в MarginNote.
2. Выберите озвучивание, объяснение, поиск, вопрос ИИ или действие с карточкой на панели Reading Space.
3. Просмотрите результат в отдельной панели или проигрывателе и при необходимости продолжите диалог.
4. Отправьте полезный материал в локальный Obsidian либо вручную обработайте выбранные данные в настройках.

## Текущее состояние

Текущий публичный снимок имеет версию **0.1.5** и требует **MarginNote 4.2.3 или новее**.

> [!IMPORTANT]
> Проверенный пакет `.mnaddon` версии `0.1.5` доступен в [Reading Space MN v0.1.5 на GitHub Releases](https://github.com/Awaker-OTE/readingspace-mn/releases/tag/v0.1.5). Собранные из исходников файлы по-прежнему предназначены для локальной разработки и проверки и не заменяют проверенный пакет, прикреплённый к Release.

Важные ограничения:

- Для функций ИИ и TTS нужны ваш провайдер, Endpoint, API Key или иные данные подключения. Сторонние учётные данные не включены.
- Автоматическая синхронизация — экспериментальная функция, сейчас она приостановлена. Сохранение настроек не загружает их автоматически; доступны только ручная загрузка и импорт iCloud.
- Cookie и состояние входа браузера остаются на устройстве и не входят в экспорт настроек или синхронизацию iCloud.
- Локальный мост Obsidian предназначен прежде всего для настольных устройств и недоступен на iPad.
- Поведение может различаться в зависимости от версии MarginNote, устройства и сети.

## Проверка и сборка из исходников

Для работы нужен MarginNote 4.2.3 или новее. Для публичной сборки также нужны Node.js 22.12 или новее, pnpm 10 или новее и системная команда `zip`.

```bash
git clone https://github.com/Awaker-OTE/readingspace-mn.git
cd readingspace-mn
pnpm install --frozen-lockfile
pnpm verify
pnpm build
```

`pnpm verify` проверяет публичные границы, квитанцию снимка и функциональные контракты. `pnpm build` создаёт в `artifacts/` файлы `.mnaddon` с постоянным и временным именем, но не устанавливает плагин, не перезапускает MarginNote, не пишет на Рабочий стол и не вызывает внутренние сервисы публикации.

Публичная сборка служит для воспроизводимости и регрессионной проверки и не заменяет принятый официальный артефакт выпуска.

## Проверяемое происхождение исходников

Этот репозиторий — управляемое публичное зеркало. Код продукта экспортируется из одного полного внутреннего Git-коммита. `PUBLIC_SOURCE.json` фиксирует исходный коммит, версию, управляемые файлы и SHA-256 каждого файла.

```bash
pnpm verify:source-snapshot
```

Файлы в `src/`, `web/` и управляемые контрактные скрипты не разрабатываются независимо в этом зеркале. Публичные README, CI, политика безопасности и оболочка сборки без локальных побочных эффектов могут сопровождаться отдельно, но не изменяют поведение продукта во время выполнения.

## Конфиденциальность и границы данных

- В репозитории нет пользовательских API Key, Bridge token, Cookie браузера, истории чатов или других пользовательских данных.
- Состояние входа браузера остаётся локальным и исключено из экспорта настроек и iCloud.
- Чувствительные категории синхронизации требуется явно выбрать и обработать вручную.
- Не публикуйте секреты, токены, Cookie, частные документы или реальные пользовательские данные в Issues, логах и скриншотах.
- Сообщайте о проблемах безопасности по правилам [SECURITY.md](SECURITY.md), не раскрывая публично детали и неотредактированные доказательства.
